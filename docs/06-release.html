Required goal checks

Create the production environment — Days36–37

  1. Create a separate labelroom-xr-production Supabase project. Use a plan that will not pause during judging; verify current dashboard terms and budget before purchase. Staging test users/data never become production user data.
  2. Back up staging schema and a non-sensitive fixture. Rehearse migrations and rollback on a fresh disposable project. Migrations must preserve prior label versions and audit.
  3. Apply the same committed migrations to production only after checking the linked project ref. Enable actual production OTP/CAPTCHA settings and verified sender; send a real outside-user code.
  4. Set production Edge secrets, exact allowed origin and AI_ENABLED. Deploy only auth-tested functions. Configure server-side cleanup every15minutes via Supabase Cron. Generate one32-byte LABELROOM_CLEANUP_SECRET, keep it in Edge secrets and Vault, and send X-Cleanup-Secret only from Cron. The cleanup endpoint requires this secret and never accepts a user session as cleanup authority. Also enable atomic model budgets.
  5. Create final Pages production from the frozen main commit; build npm run build, dist output, Node24.19.0. Public VITE env only. No third-party model key in build environment.
  6. Publish licensed demo bundle outside the static asset size limit, in allowlisted storage; store exact hash/attribution and disclose artificial label errors. Cloudflare Pages has a per-file size limit; never force a large dataset into dist.
  7. Test production URL from a fresh headset browser and an outside network. Confirm HTTPS, no embedding, CSP/headers, worker load, cached build behavior and new session access.

Stage CSP in report-only mode first, then enforce after tests. Allow only self scripts/workers, Supabase exact project HTTPS/WSS endpoints and necessary Turnstile domains. Groq is called from Edge, not directly from browser. Include required IWSDK assets/WASM according to the actual build; do not guess a restrictive policy that breaks the headset on launch.
