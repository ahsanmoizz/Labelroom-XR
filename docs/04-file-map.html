The data contract every coder uses

Canonical bundle: clip.lrx.zip. Metres; common scene-local coordinates; right-handed X/Y ground, Z up. One constant sourceOrigin translates canonical local coordinates back to source-world coordinates. No per-frame display transform ever modifies exported numbers.

clip.lrx.zip
  manifest.json
  labels.openlabel.json
  frames/000.pcd ... frames/009.pcd
  LICENSE.txt
  ATTRIBUTION.txt
  # After review export additionally:
  audit.json
  review.json
Contract fieldExact standard
Limits1–10 frames;1–200,000 points/frame;0–100 box labels/frame; ZIP≤25MiB; expanded≤40MiB. Labels JSON≤2MiB, manifest≤128KiB, audit≤2MiB, each licence/attribution text≤64KiB, maximum20ZIP members. Source local XYZ absolute value≤250m. Cuboid size each axis0.05–50m. Reject oversized input without hidden truncation.
ManifestschemaVersion:"1.0"; bundleId UUID; source{name,kind,url,licence,attribution,sha256} (kind real or synthetic-test; demo must be real); sourceOrigin:[x,y,z]; units:"meters"; coordinates:"x-y-ground-z-up"; frames[{id,timestamp,pcd,sha256,pointCount}]; hashes map {"labels.openlabel.json":sha256,"LICENSE.txt":sha256,"ATTRIBUTION.txt":sha256}, plus audit.json/review.json hashes on export. Hashes are lowercase64-character SHA256 hex over exact file bytes. Unique string frame IDs matching OpenLABEL frame keys.
TimestampsSeconds; finite; strictly increasing. Constant common coordinates are required. We do not align scans, calculate SLAM or infer missing timestamps.
PCDCanonical binary little-endian XYZ float32, FIELDS x y z, SIZE4 4 4, TYPE F F F, COUNT1 1 1, HEIGHT1, WIDTH=POINTS, VIEWPOINT0 0 0 1 0 0 0. Actual payload bytes=POINTS×12.
OpenLABEL subsetopenlabel.metadata.schema_version:"1.0.0"; global objects keyed by stable IDs; frames keyed by manifest IDs; frame object_data.cuboid contains one entry name:"bbox", val:[x,y,z,qx,qy,qz,qw,sx,sy,sz]. All IDs reference global object metadata. Preserve type/name/attributes/unrelated JSON.
Supported rotationNormalized upright quaternion xyzw; |qx|/|qy|≤1e-4 and norm error≤1e-4. Yaw about source Z, radians. Pitch/roll are rejected, never flattened silently.
Input sourceConverter can consume registered ASCII/binary XYZ PCD + the supported labels, or trusted original PandaSet pickle with explicit flag. No compressed PCD or rich extra-field general parser.
ExportOpenLABEL remains the same supported subset, original point bytes identical, updated file hashes, audit and review metadata. Intended for downstream integration after independent validation. No claim of every OpenLABEL field being understood.

ASAM OpenLABEL ↗ defines a wider standard. Our supported subset is intentional and must be visible in the upload screen and help.

Interaction and edit contracts

Desktop and VR call the same store/services. Frame switching cancels proposals. Hand selection uses tracked ray + deliberate pinch, release required. Hover does not commit. Lost tracking, app blur and XR session exit cancel active clicks. Label adjustment uses labelled source X/Y/Z controls, step1/5/10cm, and yaw1/5°. Dimensions must remain0.05–50m; total centre must remain inside±250m.

A fit is a proposal only: ≥20 eligible points, expanded region0.5m, yaw sweep±15° in1° increments,2/98-percentile bounds, centre shift≤0.5m and size change≤20%. Occlusion and point support are shown beside it. Manual edits are available when fit refuses. Three-axis freehand dragging is intentionally replaced with precise step controls to limit hand jitter.

Choose tabletop view scale0.02–0.20. Recenter, rotate and scale the display only. Default panel around0.65m wide at0.8m distance, buttons≥3cm tall, important controls within comfortable forward field. Actual headset evidence decides whether these starting numbers are usable.
