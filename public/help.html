Open LabelRoom XRPrivacy and data

Review a label with evidence.

Inspect a point cloud, compare its existing boxes, preview a change and approve it only when the geometry supports the decision.

Try the sample

  1. Complete the human check and choose Enter demo. An email address is not required for the demo.
  2. Choose Open PandaSet demo. The real licensed points include deliberately altered labels for demonstrating review. Read the dataset licence and attribution in the workspace.
  3. Select a frame and box. You can inspect, edit, keep a label with a reason, or preview removal of a confirmed duplicate.
  4. Choose Preview edit, compare with the original, then Approve and save or Reject preview. A preview does not save.
  5. Wait for the saved revision and use Export saved revision. Keep the downloaded ZIP.

Continue or start again

Refreshing while signed in reopens the same guest identity. Choose Open PandaSet demo to resume it; do not create a replacement guest to resume work. Demo access expires after 24 hours. Export first, then use Reset demo and its separate confirmation to discard that demo and start a fresh sample. An expired demo can also be reset after a refresh.

Use your own data

A permanent email-code account can save up to three private projects. Import the supported .lrx.zip format with a manifest, OpenLABEL labels, PCD frames, licence and attribution. Limits are 10 frames, 200,000 points and 100 boxes per frame, a 25 MiB compressed archive and 40 MiB expanded content. Unsupported input is rejected rather than truncated. Data must use the documented coordinates and units; arbitrary ZIPs are not supported.

When a save fails

Saved means the server acknowledged the change and its history was checked. If the outcome is unknown, use Retry same request to recover that exact operation. If another window changed the project, reload saved state before proposing another edit. A typed or pending local draft belongs to its original account, project and source bundle. Export is enabled only for a verified saved revision.

AI is optional

Check AI availability, explicitly allow inspection for the project, then ask a focused question about the selected object. The assistant can inspect measurements and suggest a bounded fit; it cannot save edits. Low point support may mean occlusion, not an incorrect label. When AI is unavailable or its budget is exhausted, manual review remains available.

Hands and comfort

Use a supported Quest browser while seated, with a clear space around you. Enter VR through the browser's VR control. Select and inspect with the hand controls, use deliberate confirmation for changes, and reset the view if it becomes uncomfortable. Stop if tracking or readability prevents a safe decision. A desktop test does not establish hands-only headset performance.

Before signing out, export the revision you want to retain. Never include session tokens or private dataset content in a support report.
