Privacy and data

This page explains how the review workflow handles data. It describes the application behavior; the release owner must keep its deployment and retention settings consistent with it.

Accounts and datasets

Email-code sign-in uses Supabase Auth. The temporary demo uses an anonymous account identifier. Cloudflare Turnstile performs the human verification check. Saved project files, label versions and the review audit are stored in the application's Supabase project with access restricted to the project owner. Do not upload confidential or personal data unless you have permission to process it in this service.

Local recovery

The browser retains its account session and stores account-scoped typed edits and pending review commands for recovery. Private views are cleared on sign-out. Browser recovery records may remain on that device; use your browser's site-data controls when you need to remove local records. Use a separate browser profile on a shared device.

Optional AI processing

When you explicitly enable project consent, inspection questions, frame and object identifiers, label information and measured inspection results are sent to Groq through the application server. Raw point-cloud files and private storage URLs are not sent by the application agent. The provider's own retention and account settings also apply. AI cannot approve or save a label change.

Retention and deletion

Private saved projects remain until their owner deletes them. Guest project access ends 24 hours after creation. The scheduled maintenance process removes expired guest projects and abandoned staging uploads; deletion timing depends on the maintenance job running successfully. Reset demo explicitly discards the selected demo and its saved history before creating a fresh sample. Hosting backups may retain data beyond its removal from the active application.

Exports and logs

An export contains the point-cloud data, corrected labels, provenance, hashes and audit history needed to use the result. Treat exports according to the dataset licence and your team's privacy requirements. Operational evidence should contain only sanitized status information and hashes; never share API secrets, session tokens or private files in a public issue.

Questions

Contact the person or team that supplied your application link for account access, deletion or data-processing questions. This software does not verify that an uploader owns the dataset rights.
